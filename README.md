# Research Workflow

`research-workflow` is a general-purpose Codex Skill for evidence-aware
research. It is designed for researchers in any discipline and supports both
early-stage exploration and later-stage review, critique, and study planning.

It turns a research question or source set into a traceable workflow:

`scope → extract → structure → compare → challenge → audit → synthesize`

The Skill can produce literature matrices, concept and variable maps,
contradiction maps, source audits, research-gap analyses, plain-language
explanations, and executable research-design options.

## Use it for

- mapping an unfamiliar research field;
- reviewing and comparing papers or reports;
- identifying theoretical, data, method, context, time, or practice gaps;
- building a conceptual framework or hypotheses;
- stress-testing a technical or academic claim;
- checking whether citations actually support a draft;
- turning a gap into research questions and a feasible design.

The entry point is [`SKILL.md`](SKILL.md). Detailed routing and output schemas
are in [`references/`](references/).

## Design principles

- Domain-agnostic: adapt to the discipline and research tradition instead of
  imposing one method.
- Evidence-first: distinguish verified findings, inferences, proposals, and
  unknowns.
- Adversarial: actively look for counter-evidence, rival explanations, and
  boundary conditions.
- Reusable: use the smallest sufficient mode for the user's actual goal.
- Honest about speed: a rapid research map is not automatically a systematic
  review or publication-ready evidence base.
